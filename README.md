# kvm-conf
config and scripts related to my gaming vm

host:
* laptop
* Nvidia dGPU + AMD iGPU
* Fedora Workstation 44
* kde wayland

For my laptop, Nvidia GPU and its audio device lives in a seperate iommu group.

## Note
1. Though Nvidia claims to have removed all virtual machine checks in their drivers, I still need many workarounds (kvm hidden, Hyper-V vendor_id, and fake battery via SSDT.dat) to make it work instead of code 43. And the official installer won't work, I need to manually extract the driver and install it in device management. Maybe that's because my GPU is too old (and you'll never need these workarounds), or bcz I did anything wrong in my setup. Double check everything.
2. All selinux-related stuff are mostly (if not all) generated by AI agents. Though I've reviewed them, I'm not an expert in selinux so... I personally don't mind that, as it can't be less secure than Arch which has no selinux at all -). TBF Fedora is much more compilicated to setup than Arch, and I'm still learning these new stuff.
